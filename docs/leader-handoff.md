## B0 与全组共用参数

| 参数 | 数值 |
|---|---:|
| 单实例零错误观测上限 U | 123.05 请求/秒 |
| 容量线 C=0.7U | 86.135 请求/秒 |
| 峰值 P=10×floor(4C/10) | 340 请求/秒 |
| 平时 BASE=P/10 | 34 请求/秒 |
| C/D 恒定负载 2C | 172.27 请求/秒 |
| 缺口阈值 SLO | 0.2 秒 |

U 来自续探 120 请求/秒阶段的 2461 个成功请求 / 20 秒；下一阶段 140 请求/秒首次出现 203 个错误。120 阶段 p99 为 509.83 ms，因此 U 只是指导书的零错误上限口径，容量线采用 0.7U。原始数据和完整阶段表见 `LAB3.md` 第 3.1 节及以下目录：

- `runs/b0-one-20261123T170415Z/`：指导书 20～100 请求/秒初轮。
- `runs/b0-extended-20261123T170836Z/`：120～200 请求/秒续探；`capacity.json` 保存计算与选择依据。

统一负载曲线总长 630 秒：

```text
34@120s,34~340@30s,340@300s,340~34@60s,34@120s
```
